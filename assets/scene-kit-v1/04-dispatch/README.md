# Диспетчерская — экран 04

`background.png` содержит всю статичную комнату. Три экземпляра `charge-dock.png` и три экземпляра `energy-capsule.png` размещаются по `manifest.json`. Номера, свет на полу и состояние заряда — отдельные PNG из `../shared`.

Пик собирается по `pik-rig.json`: корпус, задняя опора, голова, антенна, глаз и шесть частей рук. Все эти части — самостоятельные PNG с настоящей прозрачностью. Руки находятся в `rig`; их нейтральное положение и сгиб проверены отдельно. Родительские связи уже включены в общий риг.

Цельные `pik-body.png`, `pik-arm-near.png` и `pik-arm-far.png` оставлены как исходные заготовки для воспроизводимой нарезки. В итоговую сцену и `asset-index.json` они **не включены**. Для игры брать детали, перечисленные в `pik-rig.json`, а не цельные заготовки.

Капсула очищена от запечённой шахматки локальным `../tools/matte_checker.py`, параметры записаны в `energy-capsule.matte.json`. Нативные корректные RGBA других заготовок сохранены. Точные промпты встроенного генератора, путь исходной сцены и выбранные результаты находятся в JSON этой папки.

Освещение сцены применяет к Пику яркость 0.67 (кроме глаза). Мастер-PNG сохраняют цвет и могут использоваться при другом освещении. Небольшие повороты проходят без перестройки сцены; предельные углы и ограничения 2D-нарезки описаны в `rig/README.md`.
