# 01 — Главное меню

Набор для сборки первого экрана: **один цельный фон + 7 PNG с настоящей прозрачностью**. Статичная станция, небо, облака, обе скалы, ящики и древко находятся в `background.png`.

Отдельно сохранены тарелка антенны, два полотнища, корпус и голова ребёнка, корпус кота и хвост. Координаты, порядок отрисовки, точки крепления и исходный поворот флага записаны в `manifest.json`. Координаты относятся ко всему PNG с прозрачными полями. Референс 1672 × 941 остаётся без изменений.

Это генеративно восстановленные слои по плоскому превью. Фон под персонажами, скрытая центральная часть станции и небольшие детали персонажей восстановлены, поэтому набор не является пиксельной нарезкой оригинала. Хвост в превью почти скрыт и реконструирован для движения. Сохранены композиция, тёмная сине-фиолетовая палитра, тёплый контровой свет и общий художественный стиль.

Для спокойной анимации предусмотрены: лёгкий наклон головы, покачивание хвоста, небольшое движение ткани и антенны. Сидящий корпус ребёнка объединяет руки и ноги; корпус кота объединяет голову и уши. Эти спрайты рассчитаны на малые движения в исходном ракурсе. Для ходьбы, активных жестов, поворота лицом или полного оборота антенны нужны дополнительные части/ракурсы.

Логотип, кнопки, звук и декоративные надписи не запечены в фон. Их добавляет общий интерфейс. Надписи на двух полотнищах принадлежат самой ткани.

Все 7 спрайтов проверены программно: PNG RGBA, полностью прозрачные внешние пиксели и непустой силуэт. Пять PNG используют оригинальный альфа-канал генератора без изменения байтов. У хвоста и левого флага подложка удалена локальным `../tools/matte_checker.py`; у флага дополнительно очищены замкнутые отверстия ткани. Параметры и seed-точки сохранены в `*.matte.json`.

`_source/` содержит выбранные исходные результаты генератора до очистки; RGB-файлы внутри этой технической папки не предназначены для использования как спрайты. `prompts.json` хранит точные запросы и результаты всех попыток, `source-index.json` — происхождение выбранных файлов, `validation.json` — проверку итоговых PNG. Превью в `_qa/` служат только для проверки, они непрозрачные.

Проверенные изображения: `_qa/assembled.png`, `_qa/rgba-on-light-dark.png`, `_qa/cat-tail.png`, `_qa/flag-left.png`.
