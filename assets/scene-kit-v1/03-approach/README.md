# Экран 03 — Подлёт к сигналу

Готовые слои для холста 1672 × 941. Источник — `шаблоны сцен/Codex Image Sep 7, 2026, 07_50_27 PM.png`.

| Файл | Назначение | Формат |
|---|---|---|
| `background.png` | Единый фон: станция, луна, небо, острова, облака | Непрозрачный PNG, 1672 × 941 |
| `radar.png` | Отдельная тарелка с опорой | RGBA PNG, 1347 × 1167 |
| `ship.png` | Полный корпус корабля, без струй двигателей | RGBA PNG, 1448 × 1086 |
| `thruster.png` | Один мастер пламени, два экземпляра на экране | RGBA PNG, 2137 × 736 |

`manifest.json` задаёт координаты, размеры, порядок, точки вращения и общую группу корабля. Координаты относятся к целому PNG с его прозрачными полями. `assembly-plan.json` содержит точки крепления сопел и радара. Масштабирование сохраняет пропорции PNG.

Порядок сборки: цельный фон → радар → корабль → два экземпляра пламени → общие эффекты сигнала и интерфейс. Для простого покачивания корабль и оба пламени должны двигаться как одна группа `ship-rig`. Пламя отдельно меняет длину относительно точки у сопла. Радар допускает поворот в плоскости примерно ±3° вокруг нижней опоры; разворот тарелки в пространстве требует других ракурсов.

Сигнал, пауза, рюкзак и пульсирующие огни подключаются из общего набора. Их положения сохранены в `uiAnchors`. Здесь нет отдельных фрагментов неба или облаков: фон цельный.

Прозрачность проверена программно: у всех трёх спрайтов alpha от 0 до 255, с полностью прозрачной областью и полупрозрачными краями. Корабль и радар сохранены из успешной генерации без изменения пикселей. Пламя очищено локальным скриптом `finalize_assets.py`: цветовая маска убирает нейтральную шахматку, сохраняет янтарные струи и мягкую прозрачность. Нейтрально-белое ядро восстановлено внутри измеренного контура. Скрипт не применяет удаление белого к кораблю и радару.

Проверка на тёмной и светлой подложках: `qa/*-dark-light.jpg`. Собранная сцена без UI: `qa/composition.png`. Значения альфа-канала и границы видимых объектов: `qa/alpha-report.json`. Точные промпты и пути всех попыток: `prompts.json`, `source-index.json`.

Ограничение: скрытые части объектов восстановлены генератором; набор сохраняет образ и перспективу, но не является побитовым вырезанием превью. Самостоятельные PNG имеют более подробную отрисовку, чем маленькие объекты на исходнике. Ранние RGB-попытки с нарисованной шахматкой сохранены только как записи происхождения и не включены в `manifest.json`.
