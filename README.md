# LikaGame — локальное playable demo

Текущий checkpoint «Маяк-7» — короткое приключение из трёх авторских комнат. Это уже не одна тестовая задача: фиксированный `RunPlan` проводит ребёнка через три разных игровых loop, а контракты оставляют место для будущей сборки забегов из большого пула комнат. Перед первой задачей идёт короткий голосовой мульт-ввод «одинаковые группы → короткая запись → действие руками».

Демо работает как обычное React/Vite web-приложение в `BrowserHost`. В репозитории также есть `TelegramHost`, но текущая итерация предназначена для локального тестирования и не требует публикации на сервер.

## Что можно пройти

1. **E01 — диспетчерская, `allocate_equal`.** Разложить шесть капсул-связок поровну между тремя узлами: по две капсулы, то есть по четыре импульса, в каждый узел.
2. **Техническая проверка ввода.** Ввести общий заряд трёх узлов: `12`. Этот экран проверяет системную клавиатуру и не считается отдельным учебным encounter.
3. **E02 — грузовой модуль, `program_then_run`.** Растянуть один прыжок прямо на трассе; игра сама повторяет его до приёмника и вживую выводит получившиеся множители. Комната начинается с заведомо незавершённого пути `5 × 2 = 10`; голубые остановки физически совмещаются с тремя золотыми реле.
4. **E03 — ядро маяка, `array_transform`.** Выделить световой прямоугольник жестом, как рамку на рабочем столе; счётчики рядов, столбцов и общего числа огней меняются во время drag. Золотой контур и цель `4 × 6 = 24` остаются видимыми до завершения.

Неверные запуски не сбрасывают собранный вариант. E02 различает недолёт, перелёт и правильную сумму с неверным ритмом; E03 отдельно распознаёт правильное количество с неверной ориентацией. Перестановка множителей отмечается как математически верная попытка, а не как обычная ошибка.

## Локальный запуск

Нужны Node.js 24 LTS, npm и современный браузер.

```bash
cd /path/to/likagame
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Первый осмысленный tap/click разблокирует звук в соответствии с правилами браузера. Для проверки мобильной композиции используйте landscape-режим.

Прогресс и обезличенный журнал действий сохраняются локально в IndexedDB, с fallback в `localStorage`. Отдельный мета-профиль хранит ежедневные искры, «Добрую серию» и коллекционный знак первого прохождения. Эти награды не исчезают при начале нового забега. Через шестерёнку в правом верхнем углу можно:

- скачать журнал прохождения;
- начать забег заново, очистив его checkpoint, но сохранив Хранилище.

На стартовом экране можно добровольно забрать фиксированный ежедневный подарок `+1 искра`. Пропущенные дни не отнимают награды и не сбрасывают серию. Первое завершение приключения один раз выдаёт «Знак хранителя Маяка-7»; повторное прохождение не создаёт дубликат.

## Голоса и реплики

Тексты персонажей не показываются в интерфейсе: реплика звучит голосом, а говорящий персонаж двигает ртом. Tap/click по Пику или диспетчерской повторяет последнюю выбранную реплику. Переходы и запуск следующей проверки ждут фактического окончания MP3, поэтому фразы не обрываются таймером сцены.

Аудио заранее синтезируется через ElevenLabs и поставляется как 83 локальных MP3, поэтому API не вызывается во время игры. Для каждого смыслового cue подготовлено несколько авторских вариантов; конкретный вариант выбирается детерминированно для забега, а повтор не подменяет его новой фразой.

Голоса текущего прототипа:

- Пик — `rSfuQoQ3FY8SVKeraMAp`;
- диспетчерская — `Vl27Cllkuw8BhyPqus2n`.

Для регенерации аудио задайте `ELEVENLABS_API_KEY` в окружении. Для локальной разработки скрипт также проверяет внешний fallback `~/Documents/tts-play-rehearsal/.env`; другой путь можно передать через `ELEVENLABS_ENV_FILE`. Копировать ключ или `.env` в LikaGame не нужно.

```bash
npm run voices:check
npm run voices:generate
python3 scripts/generate-elevenlabs-voices.py --generate --force
```

`voices:check` выполняет бесплатный dry run, `voices:generate` создаёт отсутствующие или изменившиеся клипы, а третий вызов принудительно пересобирает весь голосовой набор. Runtime-копии находятся в `apps/web/public/assets/voice`, исходный набор — в `assets/game/voice`. API key скрипт не печатает и не записывает в manifest.

## Проверки

```bash
npm run typecheck
npm run test:run
npm run build
npm run test:e2e
```

`test:e2e` сам запускает тестовый web server по конфигурации Playwright. Одновременно держать `npm run dev` для него не обязательно.

## Структура

- `apps/web` — React shell, карты/панели, Phaser-сцена E01, анимация, локальный мета-профиль и host adapters;
- `packages/game-core` — детерминированный reducer и validators трёх игровых loop;
- `packages/contracts` — сериализуемые TypeScript-контракты и JSON Schema;
- `packages/content` — связанный `ContentBundle`, реплики с вариантами и fixed `RunPlan`;
- `assets` — curated runtime subset, лицензии и предгенерированное аудио;
- `scripts` — локальные инструменты подготовки ассетов.

Полная продуктовая спецификация, включая идеи следующих горизонтов: [GAME_DEMO_SPEC.md](./GAME_DEMO_SPEC.md).
